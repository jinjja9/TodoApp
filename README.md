# 📝 TodoApp

## 🚀 Giới thiệu

**TodoApp** là ứng dụng quản lý công việc cá nhân (To-do list) được phát triển bằng Kotlin cho nền tảng Android. Ứng dụng cho phép người dùng:
- 👤 Đăng ký, đăng nhập tài khoản.
- ➕ Thêm, ✏️ sửa, 🗑️ xoá các ghi chú công việc.
- 🗂️ Phân loại công việc theo các danh mục như Work, Personal, Shopping, Health, Other.
- 🔍 Tìm kiếm, lọc công việc theo danh mục hoặc deadline.
- 📅 Xem chi tiết, lịch các công việc.
- 🧑‍💼 Quản lý hồ sơ cá nhân.

Ứng dụng sử dụng kiến trúc MVVM hiện đại, đảm bảo code dễ bảo trì, mở rộng và dễ kiểm thử.

## 🛠️ Công nghệ sử dụng

- **Ngôn ngữ:** Kotlin
- **Kiến trúc:** MVVM (Model - View - ViewModel)
- **Database:** Room (SQLite)
- **UI:** Fragment, RecyclerView, ViewBinding, Custom Dialog
- **Navigation:** Android Navigation Component
- **LiveData & ViewModel:** Quản lý và quan sát dữ liệu theo vòng đời
- **Material Design:** Giao diện hiện đại, thân thiện người dùng
